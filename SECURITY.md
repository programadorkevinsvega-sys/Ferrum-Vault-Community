# Security policy

## Project status

Ferrum Vault Community is in pre-implementation architecture foundations. It is not a production secrets manager, has not been independently audited, and has no FIPS validation. Do not use it to store or process production secrets.

## Vulnerability reporting

A private vulnerability disclosure channel has not yet been published for this repository. Do not post exploit details, proof-of-concept code, credentials, keys, recovery material or other sensitive information in public issues or pull requests.

A confidential reporting process and response expectations must be configured and verified before the project is promoted for production use. No response-time or remediation commitment is made by this placeholder policy.

## Security claims

Security design statements in this repository describe project intent, not verified implementation. Claims about cryptographic behavior, isolation, audit guarantees, certifications or production readiness require implementation evidence and independent review.
