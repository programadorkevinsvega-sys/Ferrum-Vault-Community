# ADR-0012: Product name and trademark clearance

- **Status:** Approved as a working name; legal clearance remains pending.
- **Source decision:** Original Ferrum architecture ADR-0012, baseline commit `1fba2e2ab599ee2952a0e7e10a6dba78a66bfb79`.
- **Scope:** Public product identity.

## Decision

The working product name is **Ferrum**. The word “Vault” is not part of the product name. Rust crates and packages use the `ferrum-` prefix and should be easy to rename if clearance requires it.

The existing GitHub repository slug may remain unchanged unless the owner separately authorizes a rename.

## Pending external work

Before product publication, perform appropriate trademark, domain, GitHub and package-registry clearance. This ADR records a working name; it is not a legal search and does not guarantee availability.
