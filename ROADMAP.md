# Community roadmap

This roadmap describes public project direction, not delivery commitments. No dates or completion guarantees are implied.

## Current stage — architecture foundations

The current repository documents the intended Community boundary and project status. There is no Rust implementation, Cargo workspace, runnable service or CLI yet.

## Planned milestones

1. **Public foundation:** publish the Community project scope, edition boundaries, contribution process and approved license.
2. **Core runtime:** introduce the independently buildable Community workspace and foundational abstractions.
3. **Service interface:** add documented, versioned public APIs and operator workflows.
4. **Community capabilities:** implement the public secrets-management capabilities selected for Community, with tests and security evidence.
5. **Operational readiness:** establish deployment guidance, backup/recovery documentation, observability and security review.
6. **Ecosystem:** publish stable extension points and integrations where maintainers have approved the scope.

Enterprise-only capabilities and their internal planning details are maintained separately and are not part of this public roadmap.
