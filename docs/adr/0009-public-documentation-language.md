# ADR-0009: Public documentation language

- **Status:** Owner-approved.
- **Source decision:** Original Ferrum architecture ADR-0009, owner-approved baseline commit `1fba2e2ab599ee2952a0e7e10a6dba78a66bfb79`.
- **Scope:** Community public project materials.

## Decision

Public-facing documentation—including README, roadmap, contribution and security policies, architecture documents, and public decision records—is written in English. Source identifiers and code comments are also written in English.

## Consequences

English is the reference language for public Community documentation and contributor-facing materials. This public ADR records the language policy without reproducing internal documentation.
